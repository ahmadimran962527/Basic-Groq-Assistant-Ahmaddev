# Basic Groq Assistant 🎤🤖
### by ahmaddev

A sleek, modern AI assistant built with Python that lets you talk or type 
to powerful AI models — all powered by the Groq API.

## ✨ Features
- 🎤 Voice input — just press the mic and speak
- ⌨️ Keyboard input — type and press Enter or Send
- 🔄 Switch between 7 AI models on the fly
- 🔑 Secure — you enter your own Groq API key, nothing is hardcoded
- 🖥️ Modern dark UI — clean and minimal design
- 📦 Available as a standalone .exe — no Python needed

## 🤖 Supported Models
- Llama 3.3 70B
- Llama 3.1 8B (Fast)
- GPT-OSS 120B
- GPT-OSS 20B
- Groq Compound
- Groq Compound Mini
- Qwen 3 32B

## 🚀 How to Use (exe)
1. Download AhmadAssistant.exe from Releases
2. Run it
3. Enter your free Groq API key from console.groq.com
4. Start chatting!

## 🛠️ How to Run from Source
pip install groq sounddevice numpy SpeechRecognition pyttsx3
python voic_ai.py

## 🔑 Get Your Free Groq API Key
Visit https://console.groq.com, sign up for free and generate your key.
